# Slapton Sands Coastal Analysis

A geospatial investigation into longshore drift, beach morphology,
and coastal management strategies along the South Devon coastline.

## Overview
Primary field research at 10 systematic sites between Torcross and
Slapton Memorial Car Park. Analysed how natural processes shape
coastal management decisions using GIS and statistical methods.

## Methods
- Beach CSA profiling (10 sites, systematic sampling)
- Spearman Rank Correlation: Rs = 0.79 | p < 0.02 (98% significance)
- Chi-Squared Test for Association: X2 = 7.17 | df = 4
- Natural Vulnerability Index (NVI): wave power divided by beach CSA
- ArcGIS Online: classified NVI layer + SMP strategy overlay

## Tools
ArcGIS Online | QGIS | Excel | Survey123 | Strava GPS

## Key Finding
Beach CSA increases significantly south to north (longshore drift).
NVI values correlate spatially with SMP strategy type (HTL/MR/NAI).
